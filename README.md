# DevOps Hub — Социальная сеть для инженеров

> **Новый разработчик?** Начни с [`CONTEXT.md`](./CONTEXT.md) — это входная точка в проект.

Полноценная социальная сеть для DevOps-инженеров, системных администраторов и всех, кто работает с Linux и инфраструктурой.

## Возможности

### Для пользователей

- **Регистрация и авторизация** — через email или GitHub OAuth
- **Личный кабинет** — профиль, статистика, настройки
- **Система репутации (QoS)** — зарабатывайте репутацию за активность
- **Форум** — задавайте вопросы и помогайте другим
- **Комментарии** — обсуждайте треды, получайте апвойты
- **Теги** — находите контент по интересующим темам
- **Онбординг** — пошаговое знакомство с платформой для новичков

### Для новичков

- **Пошаговые гайды** — проверенные инструкции по настройке VPS и VPN
- **Сравнение хостингов** — 10 хостингов с реальными данными о блокировках
- **Диагностика** — интерактивный чек-лист для поиска проблем
- **Автоматические скрипты** — готовые bash-скрипты для быстрой установки

### Система репутации (QoS)

Ваша репутация отражает вклад в сообщество:

- **Новичок (0-199 QoS)** — только начали путь
- **Инженер (200-999 QoS)** — активный участник
- **Эксперт (1000+ QoS)** — признанный специалист

**Как заработать:**
- Написать комментарий: +5 QoS
- Получить апвойт на комментарий: +2 QoS
- Создать тред: +10 QoS
- Ответ принят как решение: +25 QoS

## Интеграция с GitHub

### Текущая реализация

В текущей версии реализована имитация GitHub OAuth:
- Кнопка "Войти через GitHub" создаёт пользователя с GitHub-данными
- В профиле отображается информация о подключении
- Подготовлена инфраструктура для реальной интеграции

### Для реальной интеграции с GitHub

1. Зарегистрируйте OAuth App на GitHub: https://github.com/settings/developers
2. Добавьте переменные окружения:
   ```
   VITE_GITHUB_CLIENT_ID=your_client_id
   VITE_GITHUB_CLIENT_SECRET=your_client_secret
   ```
3. Реализуйте backend для обработки OAuth callback
4. Обновите `AuthContext.tsx` для работы с реальным API

## Синхронизация с GitHub

### Текущая функциональность

- Имитация подключения GitHub в настройках профиля
- Отображение GitHub username в профиле
- Подготовка инфраструктуры для синхронизации

### Для полной синхронизации

Необходимо реализовать:
1. **GitHub API интеграция** — получение репозиториев, коммитов, issues
2. **Webhooks** — автоматическое обновление при изменениях в репозиториях
3. **Автоматический деплой** — через GitHub Actions при push в main
4. **Синхронизация контента** — импорт markdown из репозиториев
